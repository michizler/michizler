# Toolkit icons

Brand icons from [Simple Icons](https://simpleicons.org) 16.30.0, vendored by `scripts/build.py` on first run so later builds work offline.
Simple Icons publishes them under CC0 1.0. Each logo remains a trademark of its owner and is used here only to name a tool.
Brands Simple Icons doesn't carry (Microsoft, AWS, Tableau and others) are drawn as lettered badges instead; see `tools:` in `projects.yaml`.
